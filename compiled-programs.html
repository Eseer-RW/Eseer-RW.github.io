When Do Neural Networks Use Knowledge We Give Them?

Reese Wang Compiled program adoption in transformers Amin Lab, Harvard SEAS — in progress, Fall 2026
back to the work

Where this stands

This project is in progress as of Fall 2026, advised by Prof. Nada Amin (Harvard SEAS) and Joey Velez-Ginorio (UPenn). What follows is the question and the design — there are no results yet.

The setup

Neural networks are hard to interpret. Recent work by Joey Velez-Ginorio introduces Cajal, a programming language whose programs compile directly into transformer attention heads. The network is then trained normally, with the compiled piece frozen. The point is interpretability: if part of a network is a program you wrote, you have ground truth to validate your interpretation tools against.

The open question

The open question is whether networks actually use what’s installed. In the source paper’s experiments, one model relied on its compiled head almost exclusively, while a second — given a reversal algorithm on a task that requires reversing — largely ignored it and built its own solution instead.

My framing

My framing is that adoption is a competition. At every point in training the network can route through the compiled head or build the same capability in its own free parameters, and it does whichever gradient descent finds cheaper.

I’m testing this by manipulating each side:

  • Varying how available a competing shortcut solution is.
  • Scaling the compiled head’s signal magnitude.
  • Building a ladder of programs that specify increasing fractions of the target behavior.

I’m also building a continuous, training-time measure of adoption, since existing evidence is binary and measured only at convergence.
